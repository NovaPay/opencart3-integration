## Features

- Secure online payment processing via NovaPay
- Native integration with OpenCart 3
- Fast and simple setup
- Designed for e-commerce checkout scenarios

---

## Requirements

- OpenCart 3.x
- Valid NovaPay merchant account

---

## Installation

1. Download the module from this repository
2. Upload files to your OpenCart installation
3. Go to **Admin Panel → Extensions → Payments**
4. Install **NovaPay**
5. Open module settings and configure credentials
6. Enable the payment method

---

## Configuration

Configure the following parameters:

- Merchant credentials
- API access settings
- Payment status
- Additional integration parameters

---

## Usage

Once configured, NovaPay will appear as a payment method during checkout.

Customers can complete transactions using NovaPay acquiring.
